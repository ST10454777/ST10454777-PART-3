## What This App Does
A WPF desktop chatbot that teaches cybersecurity awareness.

Features:
- Interactive chatbot with greeting and name capture
- Cybersecurity quiz (Score: 11/12)
- Task manager - add tasks with reminders
- Activity Log - tracks all user actions
- Sentiment detection and keyword responses

## How To Run
1. Open CybersecurityChatbotGUI.csproj in Visual Studio
2. Press F5 / Start
3. Type your name, chat, type quiz to start quiz, type add task to add a task
